# Conversão de Kelvin para Celsius em Go

Projeto desenvolvido como desafio da Formação Go Developer da DIO.

## Objetivo

Criar um programa em Go que converta a temperatura do ponto de ebulição da água de Kelvin para Celsius.

## Fórmula

Celsius = Kelvin - 273

## Resultado

373 Kelvin corresponde a 100 graus Celsius.

## Tecnologia

- Go
